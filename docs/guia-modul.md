# Guia del mòdul

## Què aprendràs

En este mòdul estudiaràs com aplicar la sostenibilitat a decisions personals i
professionals, amb situacions pròpies del desenrotllament d'aplicacions web.
Treballaràs els impactes d'un servici digital, des del seu disseny fins als
equips, les dades, les persones i les decisions de l'organització.

El recorregut conté sis unitats. Cada una se centra en un resultat
d'aprenentatge i acaba amb una evidència que et permet aplicar el que has
treballat.

## Com utilitzar els apunts

1. Entra en la unitat indicada i llig el propòsit i l'itinerari abans de
   començar.
2. Revisa els conceptes i el cas guiat. Anota els dubtes que no pugues resoldre.
3. Completa l'activitat amb les evidències i el format que indique Aules.
4. Fes l'autoavaluació i consulta el solucionari raonat quan hages intentat
   respondre-la.
5. Porta els dubtes concrets a la tutoria o al canal que establisca el docent.

## Eines de treball

Necessitaràs un ordinador o portàtil, accés al correu vinculat a Aules i la
plataforma Aules. Treballa amb fonts identificables, registra les decisions i
conserva les evidències que et demane cada activitat.

## Autoria i ús d'eines digitals

Les activitats han de mostrar el teu procés individual: decisions, justificació
de fonts i aplicació dels conceptes. Usa les eines digitals només d'acord amb
les instruccions de cada tasca. Si tens dubtes sobre una ferramenta o sobre com
citar-la, consulta'l abans de lliurar l'activitat.
